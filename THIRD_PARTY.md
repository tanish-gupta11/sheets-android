# Third-party components

The Android APK uses Apache POI HSSF 5.5.1 to read and write Excel 97–2003 `.xls` files. Apache POI is licensed under the Apache License 2.0 license: https://www.apache.org/licenses/LICENSE-2.0

POI brings these compile dependencies, also distributed under Apache License 2.0:

- Commons Codec 1.20.0
- Commons Collections 4.5.0
- Commons Math 3.6.1
- Commons IO 2.21.0
- SparseBitSet 1.3
- Log4j API 2.24.3

The app's original source code is licensed under [MIT](LICENSE). The Windows Sheets installer is not included in this repository or APK.
